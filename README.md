# 实验物资借用管理系统

基于 SpringBoot + Vue3 + Element Plus + ECharts 的实验室全品类物资借用管理系统。

系统覆盖物资台账、借用与归还、时段预约、多级审批、采购入库、库存流水与操作审计，按「超级管理员 / 教师 / 学生」三类角色划分权限。

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Spring Boot 2.7.18（Java 8）+ Spring MVC + Spring Data JPA |
| 认证授权 | JWT（jjwt 0.11.5）+ BCrypt 密码加密 + 角色守卫 `RoleGuard` |
| 数据库 | MySQL 8（本地实例，库名 `material_borrow`）；H2 内存库用于本地无依赖验证 |
| Excel | Apache POI 5.2.3 |
| 前端 | Vue 3 + Vue Router + Element Plus + ECharts 5 + Axios + Vite |
| 构建 | Maven（后端） / npm + Vite（前端） |

## 角色与权限

| 角色 | 代码 | 定位 |
|------|------|------|
| 超级管理员 | `SUPER_ADMIN` | 全部功能，含用户、分类、系统配置、操作日志等系统管理 |
| 教师 | `TEACHER` | 业务审批与物资运营，不含基础数据维护 |
| 学生 | `STUDENT` | 借用、领用、预约，且只能看到本人数据 |

权限分两层落地：

- **前端**：`router/index.js` 用路由 `meta.roles` 控制页面可达性；页面内按钮用 `isAdmin`（超管或教师）/ `isSuperAdmin`（仅超管）控制显隐。
- **后端**：`security/RoleGuard` 在控制器方法内校验；`security/JwtAuthFilter` 另有一层路径级角色表（`/api/admin/**` 仅超管、`/api/import/**` 仅超管、`/api/export/**` 教师 + 超管），使未授权请求在参数解析之前就被拦下。

两条关键边界：

- **物资基础数据（新增 / 编辑 / 删除）与 Excel 导入仅超管**；教师可以维护物资状态（可用 / 维修中 / 已报废），但改不了数量与规格。
- **操作人身份一律取自登录态，不取请求体**，因此无法通过构造请求冒用他人名义借用或审批；归还、延期等操作另有归属校验，不能操作他人记录。

### 1. 登录 / 注册

品牌区与表单双栏布局，支持登录、注册模式切换与「记住我」。注册入口固定创建**学生**账号，并要求填写真实姓名和所属学院/部门；导师由管理员在用户管理中指定。忘记密码不提供自助找回，由超管在「用户管理」中重置。

### 2. 数据概览

- 角色专属横幅：按当前登录角色显示「超级管理员面板 / 教师工作台 / 学生工作台」
- 6 张统计卡片：物资总数、借用中、借用记录、库存预警、库存健康度、本月借用
- 8 张 ECharts 图表：分类分布环形图、设备使用率横向柱状图、借用月度对比、库存健康度仪表盘、分类消耗比例、近 7 天借用趋势、热门物资 TOP5、借用时段热力分布（7×11 格，统计开放时段 8:00–18:00）
- 最近借用记录表；「库存预警」卡片可下钻到物资管理的预警清单

**统计口径随角色变化**：与借用记录相关的指标（借用中 / 记录数 / 趋势 / 热门物资 / 设备排名 / 月度对比 / 时段热力 / 最近记录）在学生视角下只统计本人数据，教师与超管为全量；与库存相关的指标（物资总数 / 分类分布 / 库存预警 / 库存健康度 / 消耗比例）恒为全量。图表标题会同步显示为「我的……」以示区分。

### 3. 物资管理（含库存预警）

- 分类卡片行 + 关键词 / 类别 / 仅可借 / 仅看预警四项筛选
- 表格含编号、名称、类别、规格、单位、总量、可借数量、预警阈值、存放位置、设备状态
- 行内操作：领用（消耗型）、借用 + 预约（可归还型）、库存流水（分页）；支持勾选多项物资合并为**一张批量借用/领用申请**，一次审批处理全部明细；教师与超管另有「状态」维护，超管另有新增 / 编辑 / 删除与 Excel 导入导出
- **教师 / 超管自助借用免审批**：教师或超管本人经「借用 / 领用」提交时不做审批直接出库（设备/玻璃器皿转「借用中」，耗材/水/试剂直接核销「已领用」），并生成一条可在「借用记录」中归还的记录；学生提交则照旧进入「待审批」。两条通道的数量上限、最长借用天数、库存与物资状态校验口径完全一致
- **高值/稀缺物资强制审批**：物资打开「借用需审批」后，教师和超管本人也不能直接出库，必须由另一名教师或管理员审批；任何人（含超管）都不能审批自己提交的申请
- 「仅看预警」开关切换到库存预警清单：列出 `可借数量 ≤ 预警阈值` 的物资并按可借数量升序，额外显示预警阈值列。阈值默认取 `max(2, 总量 × 20%)`，可在编辑物资时调整
- 库存流水记录每一次「期初入库 / 采购入库 / 借出 / 归还」的数量变动前后值

### 4. 借用记录

- 4 张统计卡片：借用中、已逾期、今日归还、记录总数（学生视角为本人数据）
- 8 个状态页签：全部、待审批、借用中、待审批延期、已逾期、已领用、已归还、已损坏
- 操作：归还（支持部分归还，可勾选「损坏」并填写损坏说明，物资自动转维修中）、申请延期、查看审批进度时间轴；「已损坏」记录本人可见，可查看损坏说明与维修进度
- 教师与超管可导出 Excel；学生只能看到本人记录
- 自助通道产生的记录在进度时间轴上标记为「免审批自助出库」，避免被误读成「自己审批自己」；业务归属按稳定的用户账号判断，不使用可重名的真实姓名

### 5. 预约管理

- 周视图看板：7 天 × 7:00–21:00 半小时槽，按物资着色，待审批时段以虚线区分
- 新建预约弹窗：选择设备、日期、起止时间、用途；支持单次预约与周期预约（每周 / 每双周 / 每月，指定重复次数）
- 教师 / 超管预约普通物资时登记即生效，无需审批；标记「借用需审批」的物资仍进入审批
- 预约时段结束后由定时任务自动归还库存并结单，手动提前归还同样有效，不会重复回补库存
- 提交前做时段冲突检测，并提示该设备当前是否仍有未归还的在借件
- 取消预约仅本人或管理员可操作，且状态须为待审批

### 6. 审批管理

三张待办卡片，各自独立列表与「通过 / 拒绝」操作（拒绝需填写原因）：

- **待审批预约申请** —— 通过后自动扣减库存并生成借用记录
- **待审批借用申请** —— 含消耗型领用
- **待审批延期申请** —— 通过后自动延长预计归还时间

各页签通过、拒绝后分别向申请人发送站内通知。

### 7. 统计报表

4 张图表（各分类物资数量柱状图、各分类库存容量环形图、各分类借用频次柱状图、借用人排行 TOP5）与一张分类统计明细表（种类数 / 总库存 / 可借 / 借出 / 库存使用率）。

### 8. 采购入库

按供应商、备注与明细行创建入库单（明细可选已有物资，也可直接新建物资建档），入库后自动增加库存并写入库存流水；支持单号 / 供应商检索与入库单详情查看。

入库单填错可改可撤，且两种操作都在同一事务内完成，不会出现「改了一半」：

- **编辑**：先整体回退旧明细的库存与流水，再按新明细重新入库，总量与总金额随之重算
- **撤销（留痕）**：回退该单增加的库存并删除其库存流水，单据与明细**保留**并标记为「已撤销」，同时记录撤销人与撤销时间，可追溯「谁撤的、原本入了什么」
- 保护规则：若这批库存已被借出/领用，回退会造成负库存，此时编辑与撤销都会被拒绝并说明原因（不做静默截断）
- 该单自动建档的新物资，若撤销后清零且从未被借用，会一并清理，避免物资列表残留 0 库存的空记录
- 编辑与撤销均写入操作日志（`STOCK_IN_EDIT` / `STOCK_IN_REVOKE`）

### 9. 分类管理

维护物资分类字典（编码、名称、描述、排序、是否可归还）。`returnable` 决定该类物资在物资管理页走「领用」还是「借用 + 预约」，是两条通道分流的唯一依据。

### Excel 批量建档

物资管理页的「Excel批量建档」只用于**批量新增物资并建立期初库存**，不会给已有物资补货。已有物资增加库存应在「采购入库」页面创建入库单。

进入「物资管理 → Excel批量建档」后，可以查看填写说明、下载模板或直接导入文件。模板第一行是表头，至少填写以下三列：

| 列名 | 是否必填 | 内容 |
|---|---|---|
| 物资名称 | 是 | 完整名称 |
| 类别 | 是 | 分类编码或中文分类名 |
| 数量 | 是 | 大于 0 的整数 |

选填列包括规格型号、单位和存放位置；预警阈值留空时按 `max(2, 数量 × 20%)` 计算。类别编码为 `DEVICE`、`CONSUMABLE`、`WATER`、`REAGENT`、`GLASSWARE`，也可填写对应的中文分类名。系统支持 `.xlsx` 和 `.xls`，导入成功后会自动生成物资编号和期初入库流水。

### 10. 用户管理

账号列表与检索、新增用户、编辑资料与角色、重置密码为 `123456`、删除账号。接口位于 `/api/admin/**`，由路径级角色表限定仅超管可访问。

### 11. 系统配置

6 项全局参数，统一为「值 = 0 表示该项不启用」的口径：

| 配置项 | 默认值 | 含义 |
|--------|--------|------|
| `borrow_max_days` | 14 | 单次借用最长天数（按自然日计算） |
| `borrow_max_items` | 5 | 单次最多借用数量 |
| `reserve_advance_days` | 7 | 预约最多提前天数（周期预约豁免此限制） |
| `reserve_min_hours` | 2 | 预约最短时长（小时，支持小数） |
| `overdue_fine_per_day` | 0 | 逾期每日违约金（0 = 不开启） |
| `auto_cancel_hours` | 24 | 预约超时自动作废（0 = 不开启）；起算时刻为预约时段开始时刻 |

超时自动作废由定时任务每小时扫描待审批预约，作废时通知预约人并写入操作日志；同一任务还会处理已通过预约的到时自动结单。

### 12. 操作日志

记录审批、入库、物资状态变更、预约自动作废等关键动作的操作人、类型、描述、目标与时间，保留最近 200 条，只读。

## 预约与借用：两条通道的区别

可归还型物资（实验设备、玻璃器皿）同时提供「借用」与「预约」两个入口，用途不同：

| 维度 | 预约 | 借用 |
|------|------|------|
| 使用方式 | 按时段占用，适合实验室内短时使用 | 按天借走，适合急用或需带离实验室 |
| 时间粒度 | 半小时槽，7:00–21:00 | 精确到分钟的预计归还时间 |
| 适用类别 | 仅可归还型 | 全部类别：可归还型为「借用」，消耗型（耗材 / 实验用水 / 化学试剂）为「领用」 |
| 归还 | 审批通过后生成借用记录，仍在「借用记录」中归还 | 消耗型领用即核销，无需归还，也不占时段 |
| 主要约束 | 时段冲突检测、最多提前 7 天、最短 2 小时、未取自动作废、支持周期预约 | 单次最多 5 件、最长 14 天 |

学生借用、领用和预约均需审批；教师 / 超管使用普通物资时免审批，标记「借用需审批」的高值或稀缺物资仍须由其他教师/管理员审批。预约通过后会直接扣减库存并生成借用记录，提交时若可借数量为 0 会直接拒绝，不再只做提示。

## 物料分类说明

| 分类 | 说明 | 归还方式 | 示例 |
|------|------|----------|------|
| 实验设备 (DEVICE) | 可复用的仪器设备 | 可归还 | 示波器、万用表、天平 |
| 耗材 (CONSUMABLE) | 消耗性材料 | 消耗型 | U盘、透明胶带、杜邦线 |
| 实验用水 (WATER) | 各类实验用水 | 消耗型 | 去离子水、蒸馏水、超纯水 |
| 化学试剂 (REAGENT) | 化学试剂药品 | 消耗型 | 氢氧化钠、盐酸、丙酮 |
| 玻璃器皿 (GLASSWARE) | 玻璃实验器具 | 可归还 | 烧杯、量筒、容量瓶 |

「可归还」由分类表的 `returnable` 字段决定，可在「分类管理」中调整。消耗型物资的领用数量直接从库存核销，不产生归还流程。

## 快速启动

### 0. 前置条件：启动 MySQL

后端连接本地 MySQL，**启动后端前必须先确保 MySQL 服务已运行**（库 `material_borrow` 会在首次启动时自动创建）。

### 1. 启动后端

```bash
cd backend
mvn clean package -DskipTests
java -jar target/material-borrowing-1.0.0.jar
```

后端运行在 http://localhost:8088（端口已在 `application.yml` 中固定）

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端运行在 http://localhost:3000

### 3. 访问系统

浏览器打开 http://localhost:3000，演示账号见 [演示账号密码.md](演示账号密码.md)

### 4. 自动化验证

```bash
cd backend
mvn test
```

测试使用 H2 内存库，不会连接或修改 MySQL。当前覆盖批量借用、禁止自审、通知归属、教师普通物资自助预约和预约自动结单。

## 数据库

- 数据库类型：MySQL 8（本地实例）
- 连接地址：`jdbc:mysql://localhost:3306/material_borrow?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&createDatabaseIfNotExist=true`
- 用户名 / 密码：`root` / `root`
- 表结构：由 JPA 自动维护（`ddl-auto: update`），首次启动自动建库建表并写入初始数据
- 配置文件：`backend/src/main/resources/application.yml`
- 若本地 MySQL 端口或密码不同，直接改 `application.yml` 中的 `spring.datasource` 即可

## 初始数据

系统首次启动（空库）时自动初始化。`DataInit` 对各表分别以 `count() == 0` 作守卫，只补齐缺失部分，已有数据不会被覆盖：

- **8 个账号**：1 名超管 + 1 名教师 + 6 名学生，密码统一 `123456`（BCrypt 加密存储）
- **5 个物资分类** 与 **6 项系统配置**
- **51 条物料数据**：12 台设备 + 15 类耗材 + 4 种实验用水 + 10 种化学试剂 + 10 类玻璃器皿
- **18 条借用记录**：12 条借用中 + 6 条已归还（覆盖 6 位借用人、9 种用途场景）
- **库存流水**：每件物资的期初建账入库，以及演示记录的借出 / 归还流水，构成完整可追溯的台账时间线

演示记录的时间点相对首次启动时间倒推生成，借用时刻固定落在 8:00–18:00 开放时段内——否则仪表盘的「借用时段热力分布」会因全部记录落在统计窗口外而整块为空。

## 对标真实实验室系统的增强（v2.1）

以下能力是参照高校大型仪器共享平台、试剂耗材管理与实验室安全检查的通行做法补充的，用于补齐「只做台账 + 审批」的短板：

| 能力 | 说明 |
|------|------|
| 多级审批 | 申请人配置了导师（实验室负责人）时，走「导师审批 → 实验室管理员终审」两环节；未配置导师或教师自助借用则直接终审。导师不在时管理员可代处理，避免流程卡死；任何角色都不能自审 |
| 退回修改 | 审批的第三种操作：申请信息有误时退回（不作废），申请人在「借用记录」中改完可重新提交 |
| 培训 / 上机资质 | 物资可标记「需培训」，只有名单内且资质未过期的人才能预约或借用（物资行「更多 → 培训资质」维护） |
| 检定 / 维护到期 | 物资可设「下次检定日期」，到期后自动暂停预约与借用，需完成检定并更新日期 |
| 信用分 | 逾期归还按天扣分、按时归还加分；低于系统配置的最低分时暂停借用与预约，超管可在用户管理中调整 |
| 危险化学品 | 可标记危化品并登记 CAS 号、有效期、存放柜位；领用须填写第二领用人（双人领用），有效期临近或过期在列表中预警 |
| 计费与费用统计 | 物资可设机时单价（元/小时）与借用单价（元/件·天），预约与借用即时预估费用；统计报表汇总费用 |
| 部门 / 课题组维度 | 用户可归属学院（部门）与实验室、指定导师；统计报表按部门汇总借用与预约量 |
| 机时利用率 / 设备完好率 | 统计报表按「已通过预约时长 ÷ 可开放机时」计算机时利用率，并按设备状态算完好率，替代自造指标 |
| 库存盘点 | 物资管理 → 库存盘点：录入实盘数量，差异自动调整库存并写入「调整」类型的库存流水（盘盈 / 盘亏可追溯） |
| 附件资料 | 物资可上传照片 / 说明书 / 验收单（存 `backend/uploads`，单个文件 ≤10MB） |
| 标签与扫码 | 物资行「更多 → 打印标签」生成可打印标签（含编号）；扫码枪扫编号等于键盘输入，直接在物资搜索框扫码即可定位 |
| 账号治理 | 账号支持「停用 / 启用」（停用后不能登录，历史记录保留）；管理员重置密码后，本人首次登录强制改密；存在未完结借用记录的账号不允许删除，提示改为停用 |
| 批量申请 | 一次实验涉及多项物资时合并为同一申请单，整单审批、整单驳回或退回，减少重复申请与多轮审批 |
| 通知归属 | 通知查询和单条已读只允许操作当前登录人的消息；旧 Token 每次请求都会复核账号启用状态和最新角色 |
| 并发库存 | 库存变更使用行锁与乐观锁双重保护，并发审批不会覆盖库存；冲突时提示刷新重试 |
