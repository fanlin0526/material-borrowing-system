# 实验物资借用管理系统

基于 SpringBoot + Vue3 + Element Plus + ECharts 的实验室全品类物资借用管理系统。

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | SpringBoot 2.7 + Spring Data JPA + H2 数据库 |
| 前端 | Vue 3 + Element Plus + ECharts 5 + Vite |
| 数据库 | H2（文件持久化，支持 SQL 控制台） |

## 功能模块

### 1. 数据概览（Dashboard）
- 统计卡片：物资总数、借用中、记录总数、库存预警
- ECharts 图表：物料分类饼图、近7天借用趋势柱状图、热门物资 TOP5
- 最近借用记录快览

### 2. 物资管理
- 支持五大物料分类：**实验设备 / 耗材 / 实验用水 / 化学试剂 / 玻璃器皿**
- 物资录入、编辑、删除、搜索、分类筛选
- 库存预警阈值设置
- 可借数量状态高亮（充足/低库存/缺货）
- 一键借用

### 3. 借用记录
- 借用/归还全流程管理
- 状态标签页筛选（全部/借用中/已归还）
- 逾期归还红色提醒
- 部分归还支持
- 借用人/物资名称搜索

### 4. 库存预警
- 自动检测低于预警阈值的物资
- 缺货/低库存分级标记
- 库存比例进度条可视化

### 5. 统计报表
- 各分类物资数量分布柱状图
- 各分类库存容量对比饼图
- 各分类借用频次分析
- 借用人排行 TOP5
- 分类物资统计明细表（种类数/总库存/可借/借出/使用率）

## 物料分类说明

| 分类 | 说明 | 归还方式 | 示例 |
|------|------|----------|------|
| 实验设备 (DEVICE) | 可复用的仪器设备 | 可归还 | 示波器、万用表、天平 |
| 耗材 (CONSUMABLE) | 消耗性材料 | 消耗型 | U盘、透明胶带、杜邦线 |
| 实验用水 (WATER) | 各类实验用水 | 消耗型 | 去离子水、蒸馏水、超纯水 |
| 化学试剂 (REAGENT) | 化学试剂药品 | 消耗型 | 氢氧化钠、盐酸、丙酮 |
| 玻璃器皿 (GLASSWARE) | 玻璃实验器具 | 可归还 | 烧杯、量筒、容量瓶 |

## 快速启动

### 1. 启动后端

```bash
cd backend
java -jar target/material-borrowing-1.0.0.jar --server.port=8088
```

后端运行在 http://localhost:8088

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端运行在 http://localhost:3000

### 3. 访问系统

浏览器打开 http://localhost:3000

## 数据库

- 数据库类型：H2 文件持久化（`backend/data/material_borrow.mv.db`）
- H2 控制台：http://localhost:8088/h2-console
  - JDBC URL: `jdbc:h2:file:./data/material_borrow`
  - 用户名: `sa`，密码留空

## 初始数据

系统启动后自动初始化：
- **51 条物料数据**：12 台设备 + 15 类耗材 + 4 种实验用水 + 10 种化学试剂 + 10 类玻璃器皿
- **18 条借用记录**：12 条借用中 + 6 条已归还（含多位借用人、多种用途场景）
